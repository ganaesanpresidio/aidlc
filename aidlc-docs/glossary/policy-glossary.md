# Expense policy glossary (starter)

Status: STARTER — proposed by Claude on 2026-10-30, not yet confirmed by the Solution Owner. Refined in DIS-02.
Use these terms exactly. Do not use the "avoid" words.

| Term | Meaning | Avoid |
| --- | --- | --- |
| Employee | Person who submits claims. Signs in with company SSO | User, claimant |
| Claim | One submission holding one or more expense lines | Report, expense report |
| Expense line | One cost inside a claim: date, category, amount, currency, description | Item, entry |
| Receipt | File that proves an expense line (JPEG, PNG, HEIC or PDF) | Bill, invoice, attachment (when meaning the proof) |
| Attachment | Any file uploaded to a claim; a receipt is one kind | — |
| Missing-receipt declaration | Employee's signed statement and reason when a receipt is lost | Lost receipt form |
| Category | Type of cost. v1 list: Travel, Accommodation, Meals, Mileage, Other | Type |
| Receipt threshold | Amount at or above which a line needs a receipt: ₹1,000 (INR lines only; other currencies always need one) | Limit (limits are per category, set in DIS-02) |
| Retention period | How long receipts are kept before deletion: 1 year (configurable, to confirm with compliance) | Archive period |
| Draft | Claim saved but not submitted. Only the employee can see it | — |
| Submitted | Claim sent for approval. Can no longer be edited | Sent |
| Withdrawn | Submitted claim taken back by the employee before approval | Cancelled |
| Approver | Person who approves or rejects a claim | Manager (not always the same) |
| Cost centre | Budget the claim is charged to | Department |
| Base currency | Company currency used for reimbursement: INR | Home currency |
| Reimbursement | Payment of an approved claim to the employee | Refund, payout (use payout only for the unit name) |
